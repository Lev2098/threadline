# Сценарій демо-відео (≈ 4–5 хв)

[← README](../../README.md) · [Русский](../ru/video.md)

Порада: запишіть екран з двома вікнами браузера поруч, ліве та праве. Так live-оновлення видно одразу.

| # | Що показати | Що сказати |
|---|---|---|
| 1 | Термінал: `docker compose ps`, усі сервіси healthy | «Увесь стек у Docker: PostgreSQL, Redis, RabbitMQ, Elasticsearch, Django (gunicorn для HTTP, uvicorn для WebSocket), Celery, nginx» |
| 2 | Головна сторінка, таблиця | «Заголовні коментарі в таблиці, 25 на сторінку, за замовчуванням нові згори» |
| 3 | Клік по «Автор», «E-mail», «Дата» двічі | Сортування в обидва боки; URL змінюється, кнопка «назад» працює |
| 4 | Пагінація: сторінка 2, остання | «Тут мільйон записів, глибокі сторінки теж швидкі» |
| 5 | Розгорнути гілку | Каскад відповідей, «нитки», цитата батьківського коментаря |
| 6 | «Почати обговорення»: порожня форма → «Опублікувати» | Помилки по полях одразу; ім'я кирилицею → «лише латиниця» |
| 7 | Панель `[i] [strong] [code] [a]`, вкладка «Перегляд» | Прев'ю рендерить сервер без перезавантаження |
| 8 | Ввести `<script>alert(1)</script>` | Помилка «тег не дозволений»; незакритий `<i>` → «не закрито» |
| 9 | Невірна капча | Помилка, капча оновилась (одноразова) |
| 10 | Прикріпити велике фото | Після публікації воно зменшене до 320×240; клік → lightbox з зумом |
| 11 | Прикріпити TXT | Перегляд тексту в lightbox; файл >100 КБ відхиляється |
| 12 | **Друге вікно:** відповісти в першому | У другому відповідь «проростає» по нитці з підсвіткою, лічильник +1 |
| 13 | Новий корінь у другому вікні, коли перше на сторінці 2 | Плашка «1 новий коментар — показати» |
| 14 | Пошук у шапці | Повнотекстовий пошук (Elasticsearch) |
| 15 | Перемикачі UA/RU і тема | Інтерфейс двома мовами, темна тема |
| 16 | `/api/docs`, `/graphql` | REST з OpenAPI і GraphQL поверх тих самих use cases |
| 17 | RabbitMQ UI, черга `comments` | Події обробляє Celery-воркер |
| 18 | Термінал: `./loadtest/run.sh` або готовий `loadtest/reports/report.html` | Навантажувальний тест: RPS, p95 |
| 19 | Мобільний режим DevTools | Адаптивна верстка |
