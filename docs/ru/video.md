# Сценарий демо-видео (≈ 4–5 мин)

[← README](../../README.ru.md) · [Українська](../uk/video.md)

Совет: запишите экран с двумя окнами браузера рядом, левым и правым. Так live-обновления видны сразу.

| # | Что показать | Что сказать |
|---|---|---|
| 1 | Терминал: `docker compose ps`, все сервисы healthy | «Весь стек в Docker: PostgreSQL, Redis, RabbitMQ, Elasticsearch, Django (gunicorn для HTTP, uvicorn для WebSocket), Celery, nginx» |
| 2 | Главная страница, таблица | «Заглавные комментарии в таблице, 25 на страницу, по умолчанию новые сверху» |
| 3 | Клик по «Автор», «E-mail», «Дата» дважды | Сортировка в обе стороны; URL меняется, кнопка «назад» работает |
| 4 | Пагинация: страница 2, последняя | «Здесь миллион записей, глубокие страницы тоже быстрые» |
| 5 | Раскрыть ветку | Каскад ответов, «нити», цитата родительского комментария |
| 6 | «Начать обсуждение»: пустая форма → «Опубликовать» | Ошибки по полям сразу; имя кириллицей → «только латиница» |
| 7 | Панель `[i] [strong] [code] [a]`, вкладка «Просмотр» | Превью рендерит сервер без перезагрузки |
| 8 | Ввести `<script>alert(1)</script>` | Ошибка «тег не разрешён»; незакрытый `<i>` → «не закрыт» |
| 9 | Неверная капча | Ошибка, капча обновилась (одноразовая) |
| 10 | Прикрепить большое фото | После публикации оно уменьшено до 320×240; клик → lightbox с зумом |
| 11 | Прикрепить TXT | Просмотр текста в lightbox; файл >100 КБ отклоняется |
| 12 | **Второе окно:** ответить в первом | Во втором ответ «прорастает» по нити с подсветкой, счётчик +1 |
| 13 | Новый корень во втором окне, когда первое на странице 2 | Плашка «1 новый комментарий — показать» |
| 14 | Поиск в шапке | Полнотекстовый поиск (Elasticsearch) |
| 15 | Переключатели UA/RU и тема | Интерфейс на двух языках, тёмная тема |
| 16 | `/api/docs`, `/graphql` | REST с OpenAPI и GraphQL поверх одних и тех же use cases |
| 17 | RabbitMQ UI, очередь `comments` | События обрабатывает Celery-воркер |
| 18 | Терминал: `./loadtest/run.sh` или готовый `loadtest/reports/report.html` | Нагрузочный тест: RPS, p95 |
| 19 | Мобильный режим DevTools | Адаптивная вёрстка |
